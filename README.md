# Python Full-Stack Syllabus (Static)

This repository is a static, single-page representation of a 60-day Python full-stack syllabus.

Tech stack used:
- React + Vite
- TypeScript
- Tailwind CSS (used for reset + utilities; original styles preserved as global CSS)

Quick start

```bash
# install dependencies
npm install

# run dev server
npm run dev
```

Notes
- This is intentionally static. Future work can replace static content with a dynamic backend (FastAPI) and client-side data fetching.
- The page uses emoji icons for language/tool logos (e.g. 🐍 for Python, ⚛️ for React).
